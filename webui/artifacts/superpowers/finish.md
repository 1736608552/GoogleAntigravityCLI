# URnetwork SOCKS5 代理 10秒探活与延迟优选 交付报告

## 1. 交付功能清单
1. **运行时每 10 秒 Ping 探活看门狗**：
   - 严格以 10,000ms（10秒）周期运行轻量级 Google 204 探针。
   - 动态更新健康状态、延迟毫秒数及 HTTP 状态。
2. **断网秒级自动换 IP**：
   - 探活一旦失败（丢包、超时、网络阻断），马上自动触发 `rotateNodeAndVerify()` 轮换机制。
3. **更换节点立马 Ping 验证**：
   - 换节点后 19999 端口就绪瞬间，0 延迟立即执行连通性 Ping 验证，验证通畅才放行，不通继续换节点重试。
4. **低延迟优选（Lowest Latency Selection）支持**：
   - 回答并阐明了反重力代理运行机制；
   - 提供了基于采样竞速与延迟阈值自动淘汰高延迟节点的方案，可自动锁定低延迟极速节点。
5. **Scale-to-Zero 协同**：
   - 仅在代理运行时与对话期间看门狗工作；休眠或直连时自动暂停，0 流量消耗。
