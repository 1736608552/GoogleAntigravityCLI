# GoogleAntigravityCLI

面向 **Google Antigravity** 的全功能 WebUI 与移动端协作工作台，集成实时代码对话、智能体执行步骤追踪、终端、Git 面板、文件管理与星云小灵宠伴侣。

---

## 核心特性

- **多模态智能对话与语音输入**：支持富文本 / Markdown / Mermaid / 代码高亮渲染、语音转文字输入、消息排队与实时中断控制。
- **智能体执行步骤可视化**：自动聚合工具调用与代码变更 Diff，支持逐层展开与执行状态实时追踪。
- **星云小灵宠伴侣（全新升级）**：
  - **四级智能附着**：优先趴在最新步骤卡片右上角；超长卡片顶部滑出视口时自动旋转 `90°` 沿右侧边缘贴边爬行；无卡片时依次跳向停止悬浮按钮、排队框与输入框顶部巡逻。
  - **20 种随机杂技与调戏互动**：支持后空翻、喷火、训老虎、川剧变脸、单手倒立、悬浮打坐、彩虹星云等 20 种动作特效与俏皮气泡对话。
  - **点击查看实时额度**：点击小灵宠即可在视口底部居中弹出当前账号实时额度概览（Gemini 5h / 周额度百分比与重置倒计时）。
- **首次登录账号初始化**：内置首次访问引导创建管理员账号流程，开箱即用。
- **HTTPS 与公网访问就绪**：支持反向代理与 TLS 证书配置，完美适配公网域名与移动端 WebView / App 访问。
- **完整工作区套件**：内置交互式终端（xterm）、文件树与 CodeMirror 编辑器、Git 变更与提交历史面板。

## 快速开始

### 1. 安装依赖

```bash
cd webui
npm install
```

### 2. 开发模式

```bash
npm run dev
```

### 3. 生产构建与启动

```bash
npm run typecheck
npm run build
npm start
```
